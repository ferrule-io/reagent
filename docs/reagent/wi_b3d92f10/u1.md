# u1 — electron-builder: bundle plugin files into the packaged app

## Goal

Add an `extraResources` entry to `desktop/electron-builder.js` so that the four
plugin directories and the top-level MCP config from the repo root (`.claude-plugin/`,
`skills/`, `agents/`, `commands/`, `.mcp.json`) are copied into
`Contents/Resources/plugin/` inside the packaged `.app`.

This is the prerequisite for every other unit: without the files on disk inside
the bundle, neither the bridge plugin-copy logic nor the human install hint can
reference a real path.

## Scope

- `desktop/electron-builder.js`

## Approach

1. Open `desktop/electron-builder.js` and locate the `extraResources` array (currently two
   entries: the `bridge` dir and `tray-icon.png`).

2. Append a third entry that copies the plugin artefacts from the repo root (one level
   above the `desktop/` directory, i.e. `from: '../'` with a filter) into
   `Contents/Resources/plugin`:

   ```js
   {
     from: '../',
     to: 'plugin',
     filter: [
       '.claude-plugin/**',
       'skills/**',
       'agents/**',
       'commands/**',
       '.mcp.json',
     ],
   },
   ```

   The `from: '../'` path is relative to the `desktop/` directory (where
   `electron-builder.js` lives), which is the repo root — exactly where those
   directories sit.

3. No other changes to this file are needed. Do not touch signing, notarize, or
   other target entries.

## Acceptance criteria

- `git diff desktop/electron-builder.js` shows exactly one new object added to
  the `extraResources` array with `from: '../'`, `to: 'plugin'`, and the five
  filter patterns listed above.
- The five filter patterns cover `.claude-plugin/**`, `skills/**`, `agents/**`,
  `commands/**`, and `.mcp.json` (order is not significant, but all five must be
  present).
- No other line in `desktop/electron-builder.js` is modified.
