# u1 — CSS design tokens + styles for units/feedback sections + visual polish

## Goal
All styling work for the bridge web UI: introduce CSS custom-property design
tokens, apply them across existing rules, add the **missing** styles for the
"Units of work" and "Revision feedback" sections (classes app.js already emits
but `<style>` never defined), add styles for the new role/verdict badges,
per-unit status badges, and "current activity" banner that the app.js units
(u2/u3) will emit, and tighten typography / card spacing / hover / stepper /
checkpoint gate. CSS-only — no markup or JS changes.

## Scope
- `bridge/src/web/index.html` — the `<style>...</style>` block ONLY (lines ~8–224).
  This unit owns the ENTIRE `<style>` block. It may add new rules and edit
  existing rules' values, but MUST NOT touch the `<head>` outside `<style>`, the
  `<body>` markup, or the `<script>` tag.
- This unit MUST NOT touch `bridge/src/web/app.js` at all.

## Approach
1. At the top of `<style>`, add a `:root { ... }` block defining design tokens.
   Derive token values from colors already present in the file so the look is
   preserved, e.g.:
   - `--bg: #14110f; --surface: #1f1b18; --surface-2: #1a1612; --surface-3: #221d19;`
   - `--border: #3a322c; --border-soft: #2a2520;`
   - `--text: #eee; --text-dim: #ccc; --text-muted: #888; --text-faint: #666;`
   - `--accent: #c89; --accent-hover: #e8b0a0;`
   - `--ok: #2f7d4f; --ok-text: #6dba8e; --err: #8a3b2f; --err-text: #d9735c;`
   - `--gate-bg: #2a1f14; --gate-border: #a96;`
   - spacing: `--sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;`
   - radius: `--radius: 6px; --radius-lg: 8px;`
2. Replace the corresponding hard-coded hex/length values in existing rules
   (body, header, main, buttons, .item, .gate, stepper, .field-*, .checkpoint-gate,
   .gate-comment, .repos-*, .log-*, markdown, etc.) with `var(--token)` references.
   Keep visual parity; this is a refactor plus polish, not a redesign.
3. Add NEW rules for the currently-unstyled sections (match the exact class names
   app.js emits):
   - Units: `.units-section`, `.units-title`, `.units-list`, `.unit-item`,
     `.unit-title`, `.unit-scope`, `.unit-deps`, `.unit-doc`. Style `.units-list`
     as a card list (no bullets), each `.unit-item` as a bordered/rounded card
     with internal spacing; `.units-title` as an uppercase section label matching
     `.log-title`; `.unit-scope`/`.unit-deps` muted small text; `.unit-doc code`
     subtle monospace.
   - Feedback: `.feedback-section`, `.feedback-title`, `.feedback-list`,
     `.feedback-entry`, `.feedback-ts`, `.feedback-note`. Mirror the log/units
     styling: titled section, ordered list rendered as stacked entries with a
     muted timestamp and a readable note.
4. Add NEW rules for badges/banner that u2 and u3 will emit (define them here so
   those units only add markup, never CSS):
   - Role badge: `.role-badge` plus modifiers `.role-planner`, `.role-executor`,
     `.role-reviewer`, `.role-orchestrator` — small uppercase pill, distinct
     accent per role, placed inline in a `.log-entry`.
   - Verdict pill: `.verdict-pill` plus `.verdict-pass` (use `--ok`) and
     `.verdict-fail` (use `--err`).
   - Per-unit status badge: `.unit-status` plus `.status-pending`,
     `.status-running`, `.status-passed`, `.status-failed` — small pill aligned
     with `.unit-title`.
   - Current-activity banner: `.activity-banner` (prominent bordered/rounded
     bar using `--surface`/`--accent`), `.activity-banner-label` (uppercase tag),
     `.activity-banner-text` (the current line). Optional `.activity-banner.idle`
     muted variant.
5. Polish pass: tighten card spacing on `.item`, add a subtle hover state on
   `.item` (e.g. border-color toward `--accent`), refine typography line-heights,
   and visually strengthen `.checkpoint-gate` (e.g. slightly stronger border /
   inner padding) and the phase stepper (using tokens). Keep changes restrained.

## Acceptance criteria
- `git diff` shows changes ONLY within `bridge/src/web/index.html`'s `<style>`
  block; no app.js changes in this unit's diff.
- `:root` token block exists; existing rules reference `var(--...)` tokens
  (multiple existing rules converted, not just a token block added in isolation).
- Defined selectors include every one of: `.units-section`, `.units-title`,
  `.units-list`, `.unit-item`, `.unit-title`, `.unit-scope`, `.unit-deps`,
  `.unit-doc`, `.feedback-section`, `.feedback-title`, `.feedback-list`,
  `.feedback-entry`, `.feedback-ts`, `.feedback-note`, `.role-badge`,
  `.role-planner`, `.role-executor`, `.role-reviewer`, `.role-orchestrator`,
  `.verdict-pill`, `.verdict-pass`, `.verdict-fail`, `.unit-status`,
  `.status-pending`, `.status-running`, `.status-passed`, `.status-failed`,
  `.activity-banner`, `.activity-banner-label`, `.activity-banner-text`.
- A hover rule exists for `.item`.
- No new external resources, fonts, frameworks, or build steps introduced; file
  remains a single static HTML document.
