# u1 — Publish GitHub Release on tag push

## Goal

Modify `.github/workflows/package-desktop.yml` so that pushing a `vX.Y.Z` tag creates a real GitHub Release with the macOS installers (`.dmg` and `.zip`) attached as downloadable release assets. Manual (`workflow_dispatch`) runs keep a fallback artifact upload so they still produce downloadable output without attempting to cut a Release.

## Scope

- `.github/workflows/package-desktop.yml` (only this file)

## Approach

1. **Add `permissions` block to the `package-mac` job.**
   Insert a `permissions:` key directly under `package-mac:` (before `runs-on:`):
   ```yaml
   permissions:
     contents: write
   ```
   This grants the default `GITHUB_TOKEN` the write access required for `softprops/action-gh-release` to create Releases and upload assets.

2. **Replace the existing upload-artifact step with two conditional steps.**

   The current final step is:
   ```yaml
   - name: Upload macOS installers
     uses: actions/upload-artifact@v7
     with:
       name: reagent-mac
       path: |
         desktop/out/*.dmg
         desktop/out/*.zip
       if-no-files-found: error
   ```

   Replace it with:

   a. **Release step** — runs only on tag pushes:
   ```yaml
   - name: Publish GitHub Release
     if: startsWith(github.ref, 'refs/tags/')
     uses: softprops/action-gh-release@v2
     with:
       files: |
         desktop/out/*.dmg
         desktop/out/*.zip
       fail_on_unmatched_files: true
   ```
   `softprops/action-gh-release@v2` automatically uses `GITHUB_REF` as the release tag name, creates the Release if it does not exist, and attaches the listed files as assets.

   b. **Fallback artifact step** — runs only on manual dispatch (no tag):
   ```yaml
   - name: Upload macOS installers (manual build)
     if: github.event_name == 'workflow_dispatch'
     uses: actions/upload-artifact@v7
     with:
       name: reagent-mac
       path: |
         desktop/out/*.dmg
         desktop/out/*.zip
       if-no-files-found: error
   ```

3. **Verify mutual exclusion of the two new steps.**
   - A `push` to a `v*` tag sets `github.event_name == 'push'` and `github.ref` starts with `refs/tags/` — only the Release step runs.
   - A `workflow_dispatch` sets `github.event_name == 'workflow_dispatch'` and `github.ref` is a branch ref — only the artifact step runs.
   The two conditions are mutually exclusive; neither step will fire for the other trigger.

4. **No other changes.** Build steps, signing env vars, and notarization configuration are untouched.

## Acceptance criteria

- `.github/workflows/package-desktop.yml` has a `permissions: contents: write` key inside the `package-mac` job.
- The original `actions/upload-artifact@v7` step (named "Upload macOS installers") is removed.
- A step using `softprops/action-gh-release@v2` is present, gated with `if: startsWith(github.ref, 'refs/tags/')`, with `files:` listing `desktop/out/*.dmg` and `desktop/out/*.zip`, and `fail_on_unmatched_files: true`.
- A step using `actions/upload-artifact@v7` is present, gated with `if: github.event_name == 'workflow_dispatch'`, uploading the same two globs with `if-no-files-found: error`.
- All other steps (checkout, setup-node, bridge install/build/prune, desktop install/build, package macOS) are byte-for-byte identical to the original.
- No other files in the repository are modified.
