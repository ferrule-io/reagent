# u1 — Create hardened-runtime entitlements plists

## Goal

Add the two entitlements property list files that electron-builder needs to codesign the macOS app with hardened runtime. Without these files the `electron-builder.yml` `mac.entitlements` / `mac.entitlementsInherit` keys cannot reference real paths, so they must exist before any other file references them.

## Scope

The executor is allowed to touch exactly these two files (both are new — neither exists today):

- `desktop/build/entitlements.mac.plist`
- `desktop/build/entitlements.mac.inherit.plist`

No other files in the repo may be modified.

## Approach

### 1. Create `desktop/build/entitlements.mac.plist`

This is the entitlements file applied to the outer `.app` bundle itself. Write it verbatim:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
    <key>com.apple.security.cs.allow-dyld-environment-variables</key>
    <true/>
    <key>com.apple.security.cs.disable-library-validation</key>
    <true/>
  </dict>
</plist>
```

**Why these four entitlements:**
- `allow-jit` — V8 in the bundled Electron node needs JIT.
- `allow-unsigned-executable-memory` — Required alongside `allow-jit` on arm64.
- `allow-dyld-environment-variables` — Electron's own child-process spawn mechanism sets `DYLD_*` variables.
- `disable-library-validation` — The app spawns `bridge/dist/index.js` via the bundled Node runtime as a child process. Without this entitlement, Gatekeeper rejects unsigned libraries loaded by that child at runtime.

### 2. Create `desktop/build/entitlements.mac.inherit.plist`

This is the entitlements file applied recursively to all helper processes (e.g. `Reagent Helper (Renderer).app`). Write it verbatim:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>com.apple.security.cs.allow-jit</key>
    <true/>
    <key>com.apple.security.cs.allow-unsigned-executable-memory</key>
    <true/>
    <key>com.apple.security.cs.allow-dyld-environment-variables</key>
    <true/>
    <key>com.apple.security.cs.disable-library-validation</key>
    <true/>
  </dict>
</plist>
```

The inherit plist mirrors the main plist so helper processes (renderer, GPU, etc.) get the same entitlements — V8 JIT and dynamic library loading are needed in helpers too.

## Acceptance criteria

1. Two new files exist after the change:
   - `desktop/build/entitlements.mac.plist`
   - `desktop/build/entitlements.mac.inherit.plist`
2. `git diff --name-only` shows exactly these two new files. No existing files are modified.
3. Both files are valid XML plists — `plutil -lint desktop/build/entitlements.mac.plist` and `plutil -lint desktop/build/entitlements.mac.inherit.plist` both exit 0 on macOS.
4. Both files contain exactly four `<key>` entries: `com.apple.security.cs.allow-jit`, `com.apple.security.cs.allow-unsigned-executable-memory`, `com.apple.security.cs.allow-dyld-environment-variables`, `com.apple.security.cs.disable-library-validation` — each set to `<true/>`.
5. The pre-existing `desktop/build/tray-icon.png` is untouched (byte-for-byte identical).
