# u5 — README header with brand lockup

## Goal

Add a visual brand header to the root `README.md` so the repository landing page on
GitHub shows the reagent lockup above the prose. This is a single targeted edit to one
file.

## Scope

Files the executor is allowed to create or edit:

```
README.md
```

No other file may be touched. The executor may read `assets/brand/lockup.svg` (from u1)
to understand what it looks like, but should NOT embed an SVG inline in the README.
GitHub renders inline `<img>` pointing to repo-relative paths, so the approach is to
reference the SVG file that is already committed in `assets/brand/`.

## Approach

### 1. Add a header image block at the top of README.md

Prepend (before the current `# reagent` heading) the following HTML block, which
GitHub renders in the README:

```html
<p align="center">
  <img src="assets/brand/lockup.svg" alt="reagent" height="48" />
</p>
```

Using an `<img>` tag rather than `![alt](path)` markdown allows the `height` attribute
to control rendering size without cropping. `align="center"` is the conventional
GitHub-README centering pattern.

The lockup SVG has a dark background by design (tile is `#1f1b18`). GitHub's dark mode
will render it well. On light mode the tile provides enough contrast via its rounded-
square framing. If the visual review finds the dark tile looks heavy on GitHub's white
background, swap to `lockup-inverse.svg` instead — but default to `lockup.svg` first.

### 2. Keep the rest of README.md unchanged

The current `# reagent` heading and all subsequent prose must remain exactly as-is.
The only change is the prepended `<p align="center"><img .../></p>` block plus a
blank line between it and the `# reagent` heading.

Final top of file should look like:

```
<p align="center">
  <img src="assets/brand/lockup.svg" alt="reagent" height="48" />
</p>

# reagent

Phone-drivable Claude Code coding harness with human approval gates.
...
```

## Acceptance criteria

1. `README.md` starts with the `<p align="center"><img ...></p>` block pointing to
   `assets/brand/lockup.svg`.
2. All existing content (from `# reagent` onward) is preserved verbatim.
3. The SVG path in the img tag is `assets/brand/lockup.svg` (repo-relative, so GitHub
   can resolve it).
4. No other file is created or modified.
