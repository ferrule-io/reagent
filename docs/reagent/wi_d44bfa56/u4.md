# u4 — Marketplace icon

## Goal

Add a brand icon to `.claude-plugin/marketplace.json` so the plugin has a visual
identity in the Claude plugin marketplace. The icon field currently exists in the spec
but is absent from the file.

## Scope

Files the executor is allowed to create or edit:

```
.claude-plugin/marketplace.json
.claude-plugin/icon.png
```

The executor MUST NOT modify any file under `assets/`, `bridge/`, or `desktop/`.
It may read `assets/icons/marketplace-icon.png` (produced by u1) to copy the file.

## Approach

### 1. Copy the marketplace icon

```
cp assets/icons/marketplace-icon.png .claude-plugin/icon.png
```

`marketplace-icon.png` is a 128x128 PNG of the brand mark, built by `assets/build.sh`.

### 2. Update `.claude-plugin/marketplace.json`

The current file structure:

```json
{
  "name": "reagent",
  "owner": { ... },
  "plugins": [
    {
      "name": "reagent",
      "source": "./",
      "description": "..."
    }
  ]
}
```

Add an `"icon"` field to the top-level object (the marketplace convention for plugin
collection icons) and also to the plugin entry:

```json
{
  "name": "reagent",
  "icon": "icon.png",
  "owner": {
    "name": "Mike Quinlan",
    "url": "https://github.com/mjquinlan2000"
  },
  "plugins": [
    {
      "name": "reagent",
      "icon": "icon.png",
      "source": "./",
      "description": "Remote-controllable coding harness: drives a work item through investigate -> plan approval -> execute, with human gates answerable from your phone via the reagent bridge."
    }
  ]
}
```

The `"icon"` path is relative to the `.claude-plugin/` directory. No other field changes.

## Acceptance criteria

1. `.claude-plugin/icon.png` exists and is a 128x128 PNG.
2. `.claude-plugin/marketplace.json` has `"icon": "icon.png"` at the top level and
   inside the first `plugins` entry. All other fields (name, owner, description,
   source) are unchanged.
3. The JSON file remains valid (`node -e "require('./.claude-plugin/marketplace.json')"` exits 0).
4. No file outside the scope list is created or modified.
