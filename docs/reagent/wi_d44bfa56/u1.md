# u1 — SVG brand sources, tokens, and build script

## Goal

Establish the brand foundation: hand-authored SVG sources for the reagent mark and
wordmark, a brand tokens file extracted from the existing palette, and a deterministic
shell script that rasterizes every downstream PNG / .icns / maskable icon from those
SVGs. Nothing is wired into any surface here — u1 produces only the `assets/` tree that
all subsequent units consume.

## Scope

Files the executor is allowed to create or edit:

```
assets/brand/mark.svg
assets/brand/wordmark.svg
assets/brand/lockup.svg
assets/brand/lockup-mono.svg
assets/brand/lockup-inverse.svg
assets/brand/tokens.json
assets/brand/tokens.css
assets/build.sh
assets/README.md
```

No files outside `assets/` may be touched in this unit.

## Approach

### 1. Design the primary mark (`assets/brand/mark.svg`)

The mark is a 64 x 64 SVG viewport. Use a rounded-square tile (rx=12) filled with the
warm dark surface color. Inside, draw a lowercase "r" glyph rendered as a catalyst-
droplet form: a thick vertical stem with a curved arch that breaks into an open right
side — suggesting both the letterform and a pipette/drop silhouette. The accent color
is the rose gradient `#cc8899` → `#e8b0a0`. The tile background is `#1f1b18`.

Concrete SVG structure:

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <defs>
    <linearGradient id="acc" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0%" stop-color="#cc8899"/>
      <stop offset="100%" stop-color="#e8b0a0"/>
    </linearGradient>
  </defs>
  <!-- tile -->
  <rect width="64" height="64" rx="12" fill="#1f1b18"/>
  <!-- "r" stem: a thick rect from top-third to bottom -->
  <rect x="18" y="22" width="8" height="24" rx="3" fill="url(#acc)"/>
  <!-- arch: a partial arc drawn with a path, top-right quadrant only -->
  <path d="M26 22 Q26 14 34 14 Q42 14 42 22 Q42 30 34 30 L26 30"
        fill="none" stroke="url(#acc)" stroke-width="8" stroke-linecap="round"/>
</svg>
```

Tune the path and coordinates visually (the executor should adjust until the "r" reads
cleanly at 16 px in a browser preview). The goal: at 16 px the stem + arch are
distinguishable and the tile background frames it; at 512 px the drop anatomy is clear.

### 2. Wordmark (`assets/brand/wordmark.svg`)

A plain SVG text element — `reagent` — set in system-ui (stack: `system-ui, -apple-system,
sans-serif`). Use `font-size="32"` on a transparent background, fill `#eeeeee`.
viewBox should be wide enough to contain the full text (measure empirically or use
`500 50`). This avoids font-embedding complexity while staying faithful to the existing
UI font stack.

### 3. Horizontal lockup (`assets/brand/lockup.svg`)

Compose the mark (scaled to 40 x 40) to the left of the wordmark text, 12 px gap,
total viewBox height 40. Dark background variant — canonical lockup.

### 4. Mono / inverse variants

- `lockup-mono.svg` — monochrome: mark tile `#333`, glyph `#fff`; wordmark `#fff`.
  For use on coloured/photo backgrounds.
- `lockup-inverse.svg` — light background: tile `#f5f0eb`, glyph `#1f1b18`, wordmark
  `#1f1b18`. For light contexts.

### 5. Brand tokens (`assets/brand/tokens.json`)

Extract the values from `bridge/src/web/index.html`'s `:root` block verbatim. Every
variable in that block must appear. 3-digit shorthand hex values must be expanded to
6-digit form: each digit is doubled (e.g. `#eee` → `#eeeeee`, `#c89` → `#cc8899`,
`#a96` → `#aa9966`, `#bbb` → `#bbbbbb`, `#ddd` → `#dddddd`, `#888` → `#888888`,
`#666` → `#666666`, `#ccc` → `#cccccc`). Structure:

```json
{
  "color": {
    "bg":           "#14110f",
    "surface":      "#1f1b18",
    "surface-2":    "#1a1612",
    "surface-3":    "#221d19",
    "border":       "#3a322c",
    "border-soft":  "#2a2520",
    "text":         "#eeeeee",
    "text-dim":     "#dddddd",
    "text-muted":   "#888888",
    "text-faint":   "#666666",
    "text-mid":     "#cccccc",
    "text-bbb":     "#bbbbbb",
    "accent":       "#cc8899",
    "accent-hover": "#e8b0a0",
    "ok":           "#2f7d4f",
    "ok-text":      "#6dba8e",
    "err":          "#8a3b2f",
    "err-text":     "#d9735c",
    "gate-bg":      "#2a1f14",
    "gate-border":  "#aa9966",
    "warm-code":    "#c8b8a2"
  },
  "space": {
    "1": "4px",
    "2": "8px",
    "3": "12px",
    "4": "16px"
  },
  "radius": {
    "default": "6px",
    "lg":      "8px"
  }
}
```

3-digit → 6-digit expansion reference (each hex digit is doubled):
- `#eee` → `#eeeeee`  (`--text`)
- `#ddd` → `#dddddd`  (`--text-dim`)
- `#888` → `#888888`  (`--text-muted`)
- `#666` → `#666666`  (`--text-faint`)
- `#ccc` → `#cccccc`  (`--text-mid`)
- `#bbb` → `#bbbbbb`  (`--text-bbb`)
- `#c89` → `#cc8899`  (`--accent`: c→cc, 8→88, 9→99)
- `#a96` → `#aa9966`  (`--gate-border`: a→aa, 9→99, 6→66)
- `#c8b8a2` is already 6-digit (`--warm-code`, no expansion needed)

`tokens.json` MUST use fully-expanded six-digit hex values throughout.

### 7. Build script (`assets/build.sh`)

A bash script that regenerates every downstream raster from the SVG sources. It must:

1. Declare `set -euo pipefail`.
2. Resolve its own directory so it works from any cwd.
3. Produce these output files (creating `assets/icons/` subdirectory as needed):

| Output path | Source SVG | Size | Tool |
|---|---|---|---|
| `assets/icons/favicon-16.png` | `mark.svg` | 16x16 | rsvg-convert |
| `assets/icons/favicon-32.png` | `mark.svg` | 32x32 | rsvg-convert |
| `assets/icons/icon-192.png` | `mark.svg` | 192x192 | rsvg-convert |
| `assets/icons/icon-512.png` | `mark.svg` | 512x512 | rsvg-convert |
| `assets/icons/icon-maskable-512.png` | `mark.svg` | 512x512 (with 20% safe-zone padding) | rsvg-convert + convert |
| `assets/icons/marketplace-icon.png` | `mark.svg` | 128x128 | rsvg-convert |
| `assets/icons/tray-icon.png` | `mark.svg` | 16x16 | rsvg-convert |
| `assets/icons/tray-icon@2x.png` | `mark.svg` | 32x32 | rsvg-convert |
| `assets/icons/app.icns` | `mark.svg` | iconset (see below) | rsvg-convert + iconutil |

For the maskable icon, the PWA safe zone is an inner circle of ~80% diameter; add
a 10% border padding by expanding canvas: `convert -gravity center -background '#14110f' -extent 570x570 tmp.png out.png` (570 = 512 / 0.9).

For the .icns, build a temporary `iconset/` directory populated with the standard
macOS sizes:

```
icon_16x16.png      16x16
icon_16x16@2x.png   32x32
icon_32x32.png      32x32
icon_32x32@2x.png   64x64
icon_128x128.png    128x128
icon_128x128@2x.png 256x256
icon_256x256.png    256x256
icon_256x256@2x.png 512x512
icon_512x512.png    512x512
icon_512x512@2x.png 1024x1024
```

Then run `iconutil -c icns <iconset_dir> -o assets/icons/app.icns`.

Script should print `[build] generated <path>` for each output and `[build] done` at end.

### 8. Brand guidelines (`assets/README.md`)

A concise markdown file covering:
- Palette table (name | hex | usage) drawn from tokens.json.
- Mark usage rules: minimum 16 px, clear space = 1/4 tile width on all sides.
- Which SVG variant to use in which context (dark-bg → lockup; light-bg → lockup-inverse;
  single-color contexts → lockup-mono).
- "To regenerate all rasters: `cd assets && bash build.sh`".
- Note that `tokens.css` is a reference copy; index.html's inline styles are the
  authoritative runtime source.

## Acceptance criteria

1. `assets/brand/mark.svg`, `wordmark.svg`, `lockup.svg`, `lockup-mono.svg`,
   `lockup-inverse.svg` all exist and are valid SVG (open without error in a browser).
2. `assets/brand/tokens.json` contains all color, space, and radius entries from
   `bridge/src/web/index.html`'s `:root` block with fully-expanded hex values. This
   includes `text-bbb` (`#bbbbbb`) and `gate-border` (`#aa9966`). Every one of the
   22 CSS custom properties (`--bg`, `--surface`, `--surface-2`, `--surface-3`,
   `--border`, `--border-soft`, `--text`, `--text-dim`, `--text-muted`, `--text-faint`,
   `--text-mid`, `--text-bbb`, `--accent`, `--accent-hover`, `--ok`, `--ok-text`,
   `--err`, `--err-text`, `--gate-bg`, `--gate-border`, `--warm-code`, plus the four
   `--sp-*` spacing values and two `--radius*` values) must appear in the JSON.
3. `assets/brand/tokens.css` exists, is a standalone `:root` block including
   `--text-bbb` and `--gate-border: #aa9966`, is NOT imported anywhere, and
   `bridge/src/web/index.html` is unmodified.
4. `bash assets/build.sh` runs to completion (`set -e` passes) and produces all nine
   output files listed above inside `assets/icons/`.
5. `assets/icons/app.icns` is a valid .icns file (`file assets/icons/app.icns` reports
   "Apple Icon Image data").
6. `assets/icons/icon-maskable-512.png` is 512x512 (the mark occupies ~80% of the
   canvas with background padding).
7. `assets/README.md` exists and references `bash build.sh` as the regeneration command.
8. No file outside `assets/` is created or modified.
